# Изменения

## Не выпущено на рабочий сервер

### Архив сотрудников

- Добавлены архив и восстановление из таблицы сотрудников с подтверждением действия.
- Уволенные исключаются из действующего списка и выбора состава, вход отключается, история сохраняется. Физическое удаление через рабочий API запрещено.
- Сервер запрещает архивировать участника открытой смены и проверяет статус при входе, использовании JWT и выборе состава новой смены.
- Добавлены проверки прав, сохранения истории, фильтров архива, восстановления и блокировки входа.

### Уточнения плана

- Зафиксированы отложенные требования по временным исполнителям без обязательной учётной записи.
- Описаны текущие источники карт и вариант компактного просмотра GPS-отметок при приёмке.

### Навигация и список сотрудников

- Дашборд расположен первым в меню директора и РП, сотрудники — следом.
- Сотрудники отображаются компактной таблицей с отдельными колонками, границами ячеек, закреплённым заголовком и горизонтальной прокруткой на узких экранах.
- Страница сотрудников использует расширенную область на компьютере; формы редактирования и серверные ограничения сохранены.

### Локальная разработка и сотрудники

- Добавлен экран «Сотрудники» с поиском, созданием и редактированием, серверными признаками доступных ролей и действий.
- Добавлена отдельная локальная PostgreSQL, настройки разработки, генератор демопользователей и инструкция запуска.
- В режиме работы с сетью API больше не возвращает ложный успех при недоступности сервера.

### Управление пользователями

- РП может создавать мастеров и монтажников, директор — также РП.
- Запрещено назначать недоступную роль при создании и редактировании.
- Рабочий API защищает собственную запись руководителя и технические учётные записи от изменения и удаления.
- Исторический флаг суперпользователя у директора не расширяет права рабочего API.
- Добавлены проверки ролей и изолированная тестовая БД.

### Документация

- Добавлены технический TODO, правила доработки и описание управления пользователями.
- Локальные материалы и настройки помощников исключены из текущего состава публикуемых файлов.

Изоляция смен, транзакционная защита изменения состава, журнал кадровых событий и ограничение Django-admin остаются отдельными задачами.
