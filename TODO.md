# Развитие приложения

Завершённый пункт означает реализованное и проверенное поведение. Наличие страницы или API само по себе не означает готовность функции.

## Пользователи и доступ

- [ ] Кабинеты директора, руководителя проекта, мастера и монтажника.
- [x] Ограничение назначаемых ролей и защита технических учётных записей в API управления пользователями.
- [x] Интерфейс создания и редактирования сотрудников в рабочих кабинетах.
- [ ] Ограничение доступа к Django-admin техническим суперпользователем.
- [ ] Изоляция данных и журнал исправлений закрытых записей.

## Места и объекты

- [ ] Справочник офисов, баз и гаражей с геозонами.
- [ ] Создание и редактирование объектов в кабинете руководителя.
- [ ] Доступные мастеру объекты по активным статусам.
- [ ] Несколько направлений на объекте: видеонаблюдение, СКУД, домофония и другие.
- [ ] Выбор разрешённых групп и позиций работ; редактирование расценок только техническим администратором.
- [ ] Режим отчётности: комментарий либо комментарий и объёмы.

## Смены и посещения

- [ ] Начало смены в офисе или на объекте; на объекте прибытие фиксируется тем же действием.
- [ ] Добавление и исключение сотрудников с сохранением индивидуальных интервалов.
- [ ] Подтверждаемый перевод к другому мастеру без пересечения интервалов.
- [ ] Несколько посещений разных объектов за смену.
- [ ] Отклонение от геозоны и отсутствие GPS с обязательной причиной и индикатором руководителю.
- [ ] Работа без обязательных фотографий с сохранением возможности включить фото позднее.
- [ ] Завершение посещения с комментарием, объёмами либо причиной отсутствия завершённого объёма.
- [ ] Итоговая сдача объёмов по объекту без изменения прошлых посещений.
- [ ] Одновременное завершение посещения и смены одним действием.
- [ ] Защита от повторных запросов, понятные ошибки сети и восстановление состояния после перезагрузки.

## Просмотр и проверка

- [ ] Монтажник видит свои интервалы, мастера и объект.
- [ ] Руководитель видит события, состав, комментарии, объёмы и отклонения.
- [ ] Отдельное отображение времени в смене, на объектах и вне объектов без автоматического вычета обеда.
- [ ] Проверка полного сценария на Android и iOS.

## Дальнейшее развитие

- [ ] Docker Compose, автоматизация выпуска, откат и мониторинг.
- [ ] Регулярные резервные копии и проверка восстановления.
- [ ] Разделы «Что нового» и «Предложить улучшение» в приложении.
- [ ] Задания, фотоотчёты, схемы и приёмка работ.
- [ ] База знаний с инструкциями, ссылками и эталонными фотографиями по видам работ.
- [ ] Инструмент, выдача, возврат и передачи.
- [ ] Персональный табель, согласованные правила оплаты и KPI.
- [ ] Корректные Excel/PDF, акты и ведомости.
- [ ] Планирование, аналитика и уведомления.

Приложение развивается для работы при доступном интернете. Полноценная автономная работа и синхронизация отложенных событий пока не входят в текущий план.
