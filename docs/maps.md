# Карты и места отметок

## Текущее состояние

В форме объекта Django-admin используются Leaflet 1.9.4, Leaflet Draw и растровые тайлы OpenStreetMap. Поиск введённого адреса выполняется через публичный Nominatim (`/search`). Это не автоматическое определение адреса каждой GPS-отметки.

Источники: `backend/apps/objects/templates/admin/objects/projectobject/change_form.html`, `frontend/vite.config.js`. В React-приёмке координаты показываются текстом; карта события пока не реализована.

В существующей форме отключён `attributionControl`, хотя строка атрибуции задана слою. Перед использованием этой карты в новом интерфейсе необходимо обеспечить видимую подпись источника. URL тайлов привести к рекомендованному `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.

## Предлагаемое отображение

Компактная строка: место из справочника, время, результат геопроверки, расстояние до места и точность GPS (если сохранены). Кнопка «На карте» открывает карту с точкой события и геозоной. При отсутствии GPS показывать отдельное состояние, а не центр объекта вместо фактической точки.

Адрес объекта и ближайший адрес к GPS различаются. Обратное геокодирование выдаёт ориентир; оно не заменяет координаты и геопроверку. Не запрашивать адрес на каждом открытии карточки. Запросы ограничивать, результаты кэшировать; недоступность карты или поиска адреса не блокирует сохранение события.

## Смена поставщика

Разделить компонент отображения, источник тайлов и серверный сервис геокодирования. URL, атрибуция и ключи задаются конфигурацией. Геоданные события, геозоны и бизнес-правила не зависят от поставщика. Смена совместимого тайлового сервиса возможна без переработки бизнес-логики; переход на иной SDK может потребовать замены компонента отображения.

Не отправлять картографическому сервису имена сотрудников, комментарии и внутренние идентификаторы. При добавлении обратного геокодирования учитывать передачу координат внешнему сервису.

## Проверенные источники и ограничения

Проверено 23.11.2026; условия необходимо сверять перед подключением.

- [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/): публичный сервис без SLA, обязательная видимая атрибуция, ограничения массовой загрузки и правила кэширования. Бесплатные данные не означают безлимитный хостинг тайлов.
- [Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/): максимум один запрос в секунду суммарно на приложение, идентификация клиента, кэширование и возможность смены сервиса. Не использовать публичный endpoint для непрерывного фонового геокодирования.
- [Nominatim Reverse](https://nominatim.org/release-docs/latest/api/Reverse/): ближайший подходящий объект может давать неожиданный адрес.
- [Geoapify](https://www.geoapify.com/pricing/): бесплатный тариф допускает коммерческое использование в пределах квот с атрибуцией; кандидат для управляемого сервиса с последующим платным расширением. Покрытие конкретных адресов и доступность из целевых сетей ещё не проверены.

Подключение нового сервиса и автоматическое определение адресов пока не выполнены.
